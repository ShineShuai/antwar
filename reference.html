Goal
Design the best ant colony. Ants compete to collect food and bring it to their nest. Colony with the most food after 100,000 rounds wins.
Brain
All ants of a colony share one program (≤2000 instructions). No individual memory. Coordination only via pheromone markers on cells.

Rulesets: Classic and Tinyminds
Classic = the ICFP 2004 task (version 4, checked line by line): one food per ant (has_food is a boolean), death only at ≥5 enemy neighbours (a dead ant becomes 3 food, +1 if it carried), no scare rule, no drop on a blocked move, no direction/payload instructions, up to 10,000 states, 91 ants per colony on judging worlds.
v1 ships Classic only (proposed). Tinyminds = Classic + flags is a post-v1 backlog: cap2 (carry two), scare4, dropfail, ext-sense (direction, payload), altorder and more than 2 colonies. None is in the original and each adds untested surface (cap2 and dropfail interact: a blocked mover sheds food; ext-sense needs new IR ops; more colonies need N-colony marker storage, scoring and order rules). The replay descriptor keeps a rules field and v1 accepts only classic. The Simulator tab keeps its ruleset switch for experiments.
Hex grid geometry
Toroidal (wrap-around edges) pointy-top hex grid. Origin (0,0) top-left; x grows right, y grows down. Height must be even. Directions 0–5 clockwise from East.

Initialisation
Every nest cell gets one ant: pc=0, direction=0, has_food=0, resting=0. Ant ids assigned left-to-right, top-to-bottom across entire map. All markers cleared.

Surrounding & combat
4
[Tinyminds flag scare4; deferred, not in v1] Exactly 4 enemy neighbours (scared_threshold=4) → ant drops all carried food. Ant survives.
≥5
5+ enemy neighbours (kill_threshold=5) → ant killed. Cell gets 3 food (dead_ants_value) + carried food. Dead ant removed.
!
[Tinyminds flag dropfail; deferred, not in v1; Classic carries at most 1] move failure with has_food=2 → drops 1 packet on current cell, continues. has_food=1: keeps it.
Surrounded-check sequence
check_for_surrounded_ants(world, new_pos):
  act_if_surrounded(world, new_pos) // destination cell
  for dir in 0..5:
    act_if_surrounded(world, adjacent(new_pos, dir))

Called after every successful move. A single move can trigger kills in up to 7 cells.

Round order
All ants execute one instruction per round in ascending id order. resting>0: decrement, skip instruction. sleep_cycles=14 set after successful move.

flipzero p semantics
flipzero p else i:
  r = randomint(p) // r in {0, ..., p-1}
  if r == 0 → pc = pc+1 // prob ceil(16384/p)/16384, about 1/p ("zero" branch: fall through)
  else → pc = i // otherwise

The zero branch has chance ceil(16384/p)/16384, which is 1/p only for powers of two (x is 14-bit). Error vs 1/p: +0.10% at p=100, +3.76% at p=1000, +22.07% at p=5000; the relative error is at most p/16384, and p > 16384 gives 1/16384. Classic and imported ants keep this raw behaviour; authoring levels (rules, moods, choose, role mix) accept only 1 ≤ p ≤ 64 (error under 0.4%). Common usage: flipzero 2 else i = 50/50; flipzero 3 else i = 1-in-3 chance of fall-through.

RNG streams (v3, proposed)
• Simulator. The LCG above, s0 = seed mod 230, 4 warm-up steps; only flipzero draws. Sandbox and conformance default: 12345 (the official vector).
• Map generator. Its own PRNG, versioned with the generator and seeded from the same match seed. It never shares the simulator stream, so changing the generator cannot shift simulator randomness, and the reverse.
• Draws. Both streams are recorded as (state, draw count) in checkpoints.
State hash and trace (v3, proposed)
Every conformance check, replay and the “final state hash” need one canonical fingerprint. • Hash. FNV-1a 32-bit (offset 0x811c9dc5, prime 0x01000193) over the byte stream below. A regression fingerprint, not cryptographic.
• Stream (little-endian). u32 round, u32 LCG state, u32 draw count; then cells in index order (y×W+x): u16 food, u8 marker bits per colony (bit i = marker i), i16 occupant id (−1 if none); then ants in id order: u8 alive, u8 colony, u16 cell (0xFFFF if dead), u8 dir, u16 pc, u8 has_food, u8 rest.
• rest. The resting counter as in step(): 0 if the ant acts next round, 14 right after a move. An implementation that stores a wake round must convert.
• Checkpoints. After every 1,000 rounds and at the end.
• Trace. Open: the official dump format is not yet in hand. A tool needs an exporter in that format to diff against the official trace (tiny.world, sample.ant).

Brain file (.ant) — flat format
One instruction per line, numbered from 0. Max 2,000 lines. Tokens separated by whitespace. Comment: ; to end of line. Case-insensitive. No blank lines.
; instruction grammar:
sensedir ::= here | ahead | leftahead | rightahead
cond ::= friend|foe|friendwithfood|foewithfood
           | food|rock|marker m|foemarker|home|foehome
conds ::= cond conds | ε // for senseall/senseany
lr ::= left | right
addr ::= 0..1999   m ::= 0..5   k ::= 0|1|2   p ::= 1..

instruction ::=
  sense sensedir cond else addr
  | senseall sensedir conds else addr
  | senseany sensedir conds else addr
  | turn lr
  | mark m | unmark m
  | move else addr | pickup else addr | drop
  | flipzero p else addr | goto addr
  | direction d else addr | payload k else addr

Assembly (.asm): flat format with labels
The assembler turns .asm into strict .ant. name: at the start of a line (alone or before an instruction) defines a label; else name and goto name take a label or a number; blank and comment lines are allowed; addresses count instructions, not lines.
search: sense ahead food else wander
  move else search
  pickup else search
  goto home
wander: flipzero 3 else step
  turn left
  goto search
step: move else search
  goto search
; excerpt: home is the return-home part of the starter ant

Errors (with line numbers): unknown op, direction or condition; wrong arity; argument out of range; duplicate label; target ≥ length; more than 2,000 instructions after expansion; last instruction not a goto.

High-level compiler grammar (OCaml/yacc)
Structured syntax that compiles to flat .ant. Grammar originally written as an ocamlyacc parser.
toplevel ::=
  define ID ids = instr // macro with params
  | define ID instr // macro no params
ids ::= ID ids | ε

instr ::=
  sense dir cond cont
  | mark INT ; | unmark INT ;
  | pickup cont | drop ;
  | turn leftright ;
  | move cont
  | flip INT cont // = flipzero
  | direction INT cont
  | payload INT cont
  | loop instr // infinite loop (A.Loop)
  | exit ; // A.Exit
  | choose { cases } // A.Flipn — random choice
  | repeat INT instr // A.Repeat(n, instr)
  | ; // nop (A.Nop)
  | goto ID ; // labelled jump
  | { instrs } // block (A.Block)
  | ID blocks // macro apply (A.Apply)
  | ID // variable ref (A.Var)

cont ::= then instr | else instr | then instr else instr | ;
cases ::= case : instr cases | case : instr
blocks ::= block blocks | block
block ::= { instrs }
instrs ::= instr instrs | instr

Grammar caveats (review notes)
• Syntax only. The original grammar is an ocamlyacc parser (Ast.program = list of toplevels, each instr wrapped in A.Pos). Lowering to flat .ant (then/else/loop/exit/repeat/choose/goto/macros) is NOT specified; readings in this page are inferred.
• Multi-token forms: left ahead, right ahead, friend with food, foe with food, foe marker, foe home (flat .ant: one token each, e.g. leftahead).
• Terminators: high-level ; ends mark/unmark/drop/turn/exit/goto and is the empty cont/nop; in flat .ant ; starts a comment.
• Dangling else: %nonassoc THEN < ELSE → else binds to the nearest then. else instr alone = failure branch only.
• Unused tokens: LABEL, NOP, LPAR, RPAR, COMMA. goto ID ; has no label-defining production → target semantics undefined.
• Likely S/R conflict: after define ID, lookahead ID = reduce empty ids vs shift ID as instr; yacc shifts → define f x = ... may not parse. Check with ocamlyacc -v.
• Range checks only on marker/unmark/marker-cond (0..5), direction (0..5), payload (0..2), flip (≥1). repeat INT unchecked; INT unsigned; lexer not provided.
Lowering rules (v2)
• then A else B sense … else L1; A; goto L2; L1: B; L2:. A missing branch falls through; ; is the empty cont.
• loop X L: X; goto L. exit = L: goto L.
• repeat n X X unrolled n times (no counters exist), n ≤ 1000, counted against the size cap.
• choose { n cases } uniform: flipzero n else c2; case1; goto end; c2: flipzero n−1 else c3; … the last case is unconditional.
• Macros expanded at the call site, no recursion, depth ≤ 8, parameters substituted as blocks; the size cap is checked after expansion and the error names the macro.
• Labels add the production ID : so goto ID ; has a target; labels are per toplevel scope.
• S/R conflict the no-parameter form requires a block, define ID { … }; parameters use define ID ids = instr. The lookahead then decides, and the example above already conforms.

Full step() semantics
Per ant per round. resting>0: decrement, done. Else dispatch on instruction type (pc′ = pc+1):
Sense(sensing,cond,else):
  pos′ = sensed_cell(pos,sensing,dir)
  next = cell_matches(pos′,cond) ? pc′ : else
SenseAny / SenseAll: similarly with cell_matches_any/all

Mark(i): set_marker_at(pos,colony,i); next=pc′
Unmark(i): clear_marker_at(pos,colony,i); next=pc′

PickUp(else):
  if has_food>=CAP || food_at(pos)==0 → next=else // CAP = 1 in Classic
  else: food_at[pos]−=1; has_food+=1; next=pc′

Drop: food_at[pos]+=has_food; has_food=0; next=pc′

Turn(lr): direction=turn(lr,dir); next=pc′

Move(else):
  pos′=adjacent(pos,dir)
  if obstructed(pos′)||occupied(pos′):
    if dropfail && has_food==2: food_at[pos]+=1; has_food=1 // deferred flag
    next=else
  else:
    free(pos); place_at(pos′,ant)
    resting=14; check_for_surrounded_ants(pos′)
    next=pc′

FlipZero(n,else): next = randomint(n)==0 ? pc′ : else
Direction(n,else): next = dir==n ? pc′ : else
Goto(i): zero cost, resolved at load (never executed)
Payload(k,else): next = has_food==k ? pc′ : else

Pitfalls & unspecified points (review notes)
• ids: §3.2 says "positive", §4 numbers from 0 → use 0-based, row-major; act in ascending id. Ant killed earlier in the same round: skip it (ICFP 2004 does the same).
• Pace: successful move sets resting=14 → next action 15 rounds later; resting ants only decrement.
• RNG: one global stream; only flipzero consumes it (also p=1); x0 uses s4 (4 warm-up steps).
• Self-sensing: sense here friend is always true (ant sees itself), here foe always false, here friendwithfood = carrying food.
• Obstructed cell: only rock matches; home/food/marker... are false.
• Surround check: only after a successful move; destination, then dirs 0..5, applied sequentially — a kill lowers later counts, so order must match. Obstacles are not enemies. ==4: drop all food on own cell (survives); ≥5: dies, cell += 3 + carried.
• Food: food_at excludes carried food. Score = sum of food_at over a colony's nest cells (whoever dropped it — inferred).
• State: per ant only pc, direction, has_food, resting persist; pc is the only "memory" (use it as a state machine).
• Wrap: use ((v % m) + m) % m (% can be negative in C, C++, Java and JavaScript); max_y even keeps row parity consistent.
• Decisions since the original review: see the two decision cards below and the Matches tab.
Spec decisions (v2): review fixes
• flipzero range. The zero branch has chance ceil(16384/p)/16384, not 1/p (exact only for powers of two; see RNG tab). Imported Classic ants keep that behaviour; authoring levels accept only p ≤ 64.
• End of program. The loader rejects a program whose last instruction can fall through and any target ≥ length. No runtime case remains.
• Seed. One match seed, two independent streams (see RNG tab): s0 = seed mod 230 feeds the simulator LCG after 4 warm-up steps (default 12345; this page’s demo uses 99999); the map generator has its own PRNG. Stored in the replay descriptor.
• Food in nests. pickup works on any cell with food, including both nests, so ants can steal. Score = food on nest cells at the end, whoever dropped it.
• Colonies. v1 = 2 colonies. Multi-colony is deferred: it needs N-colony marker storage with a foemarker bitmask, a scoring rule for N>2 and an order-bias rule.
• Scare rule (==4 drops food). Verified against the ICFP 2004 task: the original has no scare rule (death at ≥5 only). It is the Tinyminds flag scare4, off in Classic and deferred.
• Order bias. Id 0 acts first, so the upper colony moves first each round. Matches run both colour assignments; the altorder flag (deferred) would alternate it; any such flag needs at least 500 symmetric seeds to test for bias, since 20 seeds cannot show a bias below about ±22%.
• Stale markers. Markers never decay: trails go stale unless ants unmark (an Academy lesson) or the decay flag is on.

Spec decisions (v3, proposed)
• ICFP import. Official .ant files use explicit successors (Sense dir st1 st2 cond, Move st1 st2, …). The importer targets the IR with explicit successors; it never lays out to flat text by inserting gotos, which would change timing. Classic limits count states, not flat lines.
• Goto cost (decided). In flat text a goto is a zero-cost edge resolved at load; the validator rejects goto-only cycles, so flat and ICFP forms have identical timing (the Simulator tab and src/core/asm.ts do this).
• Roles. A role mix is a flip chain at entry that jumps into a per-role loop head; roles never loop back to pc 0. If a rule’s action fails, earlier effects persist and the next rule is tried.
• Labels. Instruction names and else are reserved; a label like move: is rejected. Condition names are allowed as labels (the Assembly example uses home).
• Daily seed. Hash of the UTC date, so every timezone gets the same map.
• Limits. An implementation that stores cell indices in 16 bits supports at most 65,536 cells (200×200 = 40,000 fits); assert at load. Food per cell ≤ 65,535 in a 16-bit counter. A .map digit is 1–9 packets; the JSON wrapper carries larger counts.
• Versions. The site keeps the last N released sim bundles under /vN/. A link names its version and final state hash; older links show “unverifiable” instead of silently diverging.
