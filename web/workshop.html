Tinyminds workshop

How to play

Write one program per colony. Every ant runs its own copy, sees only its own cell and the three cells ahead, and can only leave scent marks. After 100,000 rounds the colony with more food on its own nest wins.

Brains are official .ant (Sense Ahead 1 3 Food, one state per line) or flat assembly (sense ahead food else 3, labels, goto costs nothing). Pick an example, edit, press Reset. Full reference.

Rules language

The easiest way to write a brain: ordered rules, the first one that matches fires, every round, from the top. Rules are grouped in moods; switch changes mood for free.

when food ahead and not home ahead -> step
when carrying -> switch home
otherwise wander

Conditions: food rock foe friend home, marker N, carrying, each with here ahead left ahead right ahead. Actions: move step pickup drop turn left|right|around|random mark N unmark N wander explore switch MOOD. If an action fails, the next rule is tried. Add kit trail and kit foodtrail for return home, follow trail, lay trail, roam. Pick "Trail forager" as an example; the note under the editor shows size and warnings.
