Tinyminds workshop

How to play

Write one program per colony. Every ant runs its own copy, sees only its own cell and the three cells ahead, and can only leave scent marks. After 100,000 rounds the colony with more food on its own nest wins. A world file with more hills (letters a to z) brings more colonies, one brain each; Rules switches to “up to 26 colonies” by itself.

Brains are official .ant (Sense Ahead 1 3 Food, one state per line), flat assembly (sense ahead food else 3, labels, goto costs nothing), rules or a script. Pick an example, edit, press Reset. Full reference.

Rules language

The easiest way to write a brain: ordered rules, the first one that matches fires, every round, from the top. Rules are grouped in moods; switch changes mood for free.

when food ahead and not home ahead -> step
when carrying -> switch home
otherwise wander

Conditions: food rock foe friend home, marker N, carrying, each with here ahead left ahead right ahead. Actions: move step pickup drop turn left|right|around|random mark N unmark N wander explore switch MOOD. If an action fails, the next rule is tried. Add kit trail and kit foodtrail for return home, follow trail, lay trail, roam. Pick "Trail forager" as an example; the note under the editor shows size and warnings.

Script language (level 3)

Start a brain with define for structured code with macros. A sense takes a then and an else; goto costs nothing; senses and actions cost one round each. The program starts at main (or the last define) and runs again when it ends.

define wander { choose { case: turn left ; case: turn right ; case: move ; } }
define main { loop { sense ahead food then { move ; pickup ; } else wander } }

Also repeat N, exit, flip N, mark N ;, label:, macros with block parameters (define twice b = { b b }). Pick "Starter (script)" as an example.

Evaluate (two brains, many worlds)

Plays one brain against another on many worlds, once per colour, on your cores. The numbers are those of cli/tourney.ts, and the command that reproduces them is shown. Mirrored worlds give both colonies the same terrain; the interval is approximate (the two games of a world are not independent).
