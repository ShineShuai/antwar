The project

About the numbers

Games on one world are not independent (both colours play it), so intervals are approximate. A result of “no clear difference” or “no bias found” is not proof. The league scores 2 points for each colony out-scored and 1 for each tie, the n-colony ranking proposed in docs/MATCH.md, not the contest's. Workers: the games run on that many Web Workers; the default leaves one core to the page.
